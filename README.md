# ✅ Level 2 — Task 3: To-Do Web App

An interactive **To-Do Web App** that allows users to create, manage, edit, complete, and delete daily tasks.

This project was created as **Level 2 — Task 3** of my Web Development & Designing Internship at Oasis Infobyte.

## ✨ Features

- ➕ Add new tasks
- 📋 Display newly added tasks in the **Pending Tasks** list
- ✅ Mark tasks as completed
- 🔄 Move completed tasks to the **Completed Tasks** list
- ✏️ Edit task text
- 🗑️ Delete tasks
- 🔢 Display pending and completed task counts
- 🕐 Display task timestamps *(if implemented)*
- 💾 Store tasks using `localStorage` *(if implemented)*
- 💬 Friendly empty-state messages
- 📱 Responsive and user-friendly interface

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
- **localStorage** *(if implemented)*

## 📋 Task Management

The application organizes tasks into two sections:

### ⏳ Pending Tasks

Newly created tasks are displayed in the Pending Tasks section. Users can edit, complete, or delete them.

### ✅ Completed Tasks

When a task is marked as complete, it moves from the Pending Tasks section to the Completed Tasks section.

## 🔢 Task Counters

The application displays the number of tasks in each section:

- **X Pending**
- **Y Completed**

The counters update as tasks are added, completed, edited, or deleted.

## 💾 Data Persistence

If `localStorage` is implemented, tasks remain available even after refreshing the browser.
